fang-scan — security headers checker

Paste raw HTTP response headers and fang-scan grades them A–F, flagging missing or weak protections with a concrete fix for each one.

How do I get a site's headers?

Run this in a terminal and paste the output above:

curl -sI https://example.com

Or open your browser DevTools → Network tab → select the document request → copy the response headers.

Private by design: everything runs in your browser — headers are never uploaded, stored, or sent anywhere.
